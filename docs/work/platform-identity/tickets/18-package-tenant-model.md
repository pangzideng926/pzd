# 18 套餐与租户模型

## 目标

租户有套餐、状态、到期时间、加密连接串与库版本；套餐决定该租户能分配哪些权限码。

## 需求依据

- [architecture.md](../../../architecture.md) §4、§6.3
- [spec.md](../spec.md) AC-02、AC-12
- 拆分依据：[consensus.md](../../pzd-v1/consensus.md) M3.2

## 范围与非范围

- 做：套餐聚合（编码、名称、权限码集合）、租户聚合（编码、状态机、到期时间、加密连接串、库版本）、默认套餐 `BASIC` 初始化（含 V1 全部权限码）、分配权限码时的套餐上限校验。
- 不做：不做套餐计费、不做套餐维护界面（期外）、不做租户自助注册。

## 责任文件范围（认领时在群里先说清）

`src/Pzd.Platform/Domain/**`、`Application/**`、`Infrastructure/**`、`tests/Pzd.Platform.UnitTests/**`。不碰 `db/master/` 已有脚本（新加迁移文件即可）。

## 关键接口与依赖

- 前置票：17
- 对外契约：租户状态机取值被 07、21、24 号票依赖；`BASIC` 套餐编码在 19 号票种子里使用。

## 步骤

1. 建套餐与租户聚合，状态机只允许合法转移。
2. 实现连接串加解密（Data Protection）。
3. 迁移脚本插入 `BASIC` 套餐。
4. 单测覆盖状态机非法转移、套餐上限校验。

## 验收标准

- [ ] 租户记录含编码、状态、套餐、到期时间、加密连接串、库版本。
- [ ] 连接串在库中为密文，仅内存可解密。
- [ ] 非法状态转移返回 `Result.Failure`。
- [ ] 分配超出套餐的权限码被拒绝（422 来源错误）。
- [ ] `BASIC` 套餐由迁移初始化，含 V1 全部权限码。
