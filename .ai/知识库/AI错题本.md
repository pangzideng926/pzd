# AI 错题本（空白模板）

本仓只维护格式。真实事故保存在已明确资料根：独立项目使用本项目知识库，已接入共享工作区的项目沿用共享知识库；不按每日、每周另建副本。范围与自动修复见[每日复盘](../规则/每日复盘.md#复盘通用约定)，归类与计次见[错题本维护](../规则/每日复盘.md#错题本维护)。

```markdown
## AI-NNN：<一句可执行规则>
- 关键词：<需求理解／设计实现／验证交付／规则协作／工具环境；相关项目、模块和检索词>
- 适用范围：<项目、版本、环境和契约；不适用边界>
- 场景：<返工／不该合入／验证粗糙／执行遗漏／规则冲突等>
- 事故：<统一事故标识；仓库＋事故 SHA／issue，或项目＋任务／会话标识＋具体事件定位> — <触发条件、已确认根因、后果及证据链接；跨仓关联范围>
- 事故 ID：<稳定标识；每个独立事故一行，同一事故复用同一 ID>
- 事故 ID 完整：<是／否；只有历史独立事故清单已核实完整才填是>
- 证据：<实际验证／代码或契约直接对照／历史助手报告；分别注明支持的结论>
- 复发诊断：<仅独立复发填写：原因标签、事发规则版本／加载／动作／验证证据、相应改进；不足则原因未明>
- 修复：<待修复／已修改待验证／已验证，注明 commit 或未提交状态；失败及阻塞另记>
- 同类排查：<范围、命中位置与处理结果>
- Done right：<正确示例及适用条件；建议方案注明待验证>
- Seen N× (YYYY-MM-DD, YYYY-MM-DD).
- 验证：<代码按开发流程 L2；纯协作或文档记录来源、文件版本／指纹、核验方法、结果和未覆盖项；不适用字段不伪造>
```

仅收录有证据的根因；待核实线索留在复盘报告。已确认根因与修复完成分开，待修复教训可以保留，未验证做法不写成成功经验。旧编号和 Seen 保留，旧条目仅在实质更新时补字段；同一事故的补修、日周复用与跨仓引用不增加 Seen。条目不按日期或项目拆库。

复发原因按[复发诊断](../规则/每日复盘.md#复发诊断)核对；结构检查见[错题本只读检查](../规则/每日复盘.md#错题本只读检查)。事故 ID 是可选的计次台账；历史不完整时保持未知，不凭已有 Seen 数量生成占位 ID，检查通过也不代表事实已复核。
