```
CS1739: "Error"的最佳重载没有名为"Code"的参数          ← new Error(Code: …, Message: …)
CS0200: 无法为属性或索引器"Error.Message"赋值 - 它是只读的  ← e with { Message = … }
```

## 四、with 语义对照（我自己跑，不采信转述）

李总与锋哥上一轮的结论表面冲突，实际是两种写法。三种写法各跑一遍：

```
A 主构造 + 属性初始化器校验      with 改 Code => 成功，得到「坏码」   ← 绕过
B 主构造 + init 访问器体内校验   with 改 Code => 抛 ArgumentException  ← 拦得住
C 无校验                        with 改 Code => 成功，得到「坏码」   ← 绕过
```

**判据是「校验写在哪」，不是 `class` 还是 `record`。** 李总、锋哥两边都对。
