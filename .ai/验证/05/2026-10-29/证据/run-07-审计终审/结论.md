## 二、本次新增的 8 行源码改动（超出「只核两行」范围，故全套重审）

```csharp
private readonly ReadOnlyCollection<IDomainEvent> _domainEventsView;
protected AggregateRoot() => _domainEventsView = _domainEvents.AsReadOnly();
public IReadOnlyList<IDomainEvent> DomainEvents => _domainEventsView;
```

逐条核对：

- **字段初始化顺序正确**：`_domainEvents = []` 有字段初始化器，按 C# 规则在构造体之前执行，所以构造体里 `_domainEvents.AsReadOnly()` 拿到的不是 null。
- **`protected AggregateRoot()` 与原来的隐式构造等价**：`abstract class` 无显式构造时编译器生成 `protected` 无参构造，显式写出来公开签名不变，派生类行为不变。
- **`AsReadOnly()` 返回的是实时视图，不是快照**：`ReadOnlyCollection<T>` 包装的是 `_domainEvents` 同一实例，后续 `Raise` / `ClearDomainEvents` 都能被观察到。既有用例 `事件按添加顺序收集`（先构造、后 Raise、再读）能覆盖这一点。
- **强转防护仍成立**：返回类型仍是 `ReadOnlyCollection<IDomainEvent>`，`(List<IDomainEvent>)` 强转抛 `InvalidCastException`，`(IList<IDomainEvent>)` 强转成功但 `Add` 抛 `NotSupportedException`，两条断言都在。
- **行为变化已公告**：`DomainEvents` 现在反复访问返回同一实例。锋哥在重新公告里写了「别拿引用相等判断事件有没有变，要判就比 `Count` 或内容」——这条提醒是必要的，缓存确实会让 `ReferenceEquals(left, right)` 恒真。
