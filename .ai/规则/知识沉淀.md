# 知识沉淀

触发：产生可复用结论需要写入知识库、更新记忆导航，或用户要求“记住/纠正/更新记忆”时读取。检索与使用已有知识见[协作与知识](协作与知识.md)；单一正文要求见[工作原则 B7](工作原则.md#b-执行协议)。

本文件中的 `.ai/` 路径以已确认的实际资料根为基准：独立项目默认项目自身，已接入共享工作区沿用共享位置；规则仓库的空白模板不是实际知识库。周期报告位置见[日周共用约定](每日复盘.md#复盘通用约定)，报告只引用唯一知识正文。

## 知识库增量更新

- **触发条件**：有价值的工作或交接产生了新的可复用业务规则、已定位根因、验证有效的排障方法、重要反例或用户明确表达的长期偏好时，结束时沉淀一次；没有新增知识则跳过。
- **周期性蒸馏**：每周任务历史蒸馏的执行步骤与报告位置见[每周蒸馏](每周蒸馏.md)。
- **统一位置**：长期经验写入 `.ai/知识库/索引.md` 指向的主题文件，优先补充现有条目；确有新主题时才新建文件并更新导航。
- **限定读取**：优先使用本次会话、实际改动和验证结果，只检索相关条目；不为一次沉淀全量扫描会话、日志、代码或知识库，不重建整库索引、覆盖统计或摘要。用户明确要求全面整理时才扩大范围。
- **保留来源**：新结论注明日期、项目及适用版本或环境，附可追溯证据，如仓库与提交、文件及定位、测试记录、会话 ID 或消息时间；无需凑齐全部字段，不编造来源，优先引用已有交接或验证产物。
- **证据强度**：分别标明“用户确认”“实际验证”“历史助手报告”“待验证推测”；提问不证明完成，提交或构建成功不等于部署或现场验收。已证实结论与建议回归点分开记录。
- **先去重**：按“项目/适用范围＋问题或规则＋核心结论”比较已有条目；相同事实只补充新的证据、边界或验证，不因工具或会话不同重复建条，无实质新增则不写入。
- **纠正旧结论**：新证据推翻旧结论时更新现行结论，简短保留纠正日期、旧结论失效原因、新依据及替代关系；仅环境或版本不同则并列注明。证据不足标为待核验，不静默覆盖或删除反例。
- **时效复核**：在再次使用、用户纠正、版本/环境改变或来源失效时核验相关条目，不按日期机械作废、不默认定时扫描。暂不能核验时保留原结论并标注边界；发现已停用/已替代内容时同步其导航和直接引用。
- **术语与 ADR**：项目术语表和架构决策记录只保存本项目新增或特有内容，优先引用既有共享结论；产生跨项目的持久结论时在知识库保留单一正文，项目文档引用它。
- **敏感信息**：不写入原始聊天全文、凭据（含密码、令牌、连接串）或敏感业务数据（硬闸 A4）。

## 条目结构与状态

- 一个条目回答一个可复用问题。优先更新已有正文；保留既有 K 编号，新条目可用稳定语义 ID，不因排序/日期变化重编号。拆分过长主题时先检查引用，不默认整库迁移。
- 条目 ID 在知识库内全局唯一，跨文件同名即冲突；新增前在已明确资料根的知识库中针对拟用 ID 定向检索，只核对命中位置，不读取无关主题正文。无法完成唯一性核对时标未确认，不把未查到当作已确认无冲突。发生冲突时保留已有外部引用的编号，另一方改为已确认未用的 ID，并在两处注明更正日期与原因，不靠“按文件重新起编”解释。
- 新增及本次实质更新的普通知识条目采用以下最小格式；旧条目按需补齐，未知写“未记录”，不得为了补字段编造来源或核验日期。正文保留必要原因、反例和验证边界，检索摘要不替代正文。
- 错题条目的格式、修复与验证状态、计次沿[专用模板](../知识库/AI错题本.md)和[错题本维护](每日复盘.md#错题本维护)，不叠加本节通用字段及状态枚举；来源、适用范围、证据真实性和去重要求仍适用。

```markdown
## <稳定ID>：<问题或结论>
关键词：<用户问法、业务词、技术标识或同义词>
适用范围：<项目/版本/环境；不适用边界>
状态：<现行 / 待核验 / 已替代 / 已停用>
证据：<用户确认 / 实际验证 / 历史助手报告 / 待验证推测；混合时逐项区分>
最后核验：<实际核验日期及范围；未复验则注明，不用整理日期代替>
复核条件：<版本/配置/部署变化、用户纠正或其他明确触发条件>
有效至：<仅有明确截止日时填 YYYY-MM-DD；否则省略，不推算统一保质期>
替代条目：<已替代/已停用时指向新条目或停用决定；否则省略>

结论：<做什么、为何有效、何时不适用>
来源：<证据日期＋文件/提交/消息定位；优先稳定ID或锚点，行号作为补充>
更新：<有纠正时记录日期、原因和替代条目；无则省略>
```

- “状态”表示当前适用性，“证据”表示依据强度，二者独立；现行不等于已实测，构建/测试通过不等于部署/现场通过。未知状态显示未标注，不根据检索命中情况猜测。
- 现行条目才作为当前经验候选；待核验条目提供调查线索，已替代/已停用条目保留历史与反例，并指向替代依据。检索仍可返回它们，不能自动照做。
- 存储分工：源码和现场状态用于核验事实；项目文档保存项目约定与状态，项目索引负责导航，ticket/交接保存阶段状态；共享知识库存可复用工程经验；个人知识资料保存个人和跨项目背景。项目设计意图以现行约定为依据，实际运行情况以现场证据核验；冲突须查证并标明，不用历史笔记替代验收。
- 个人知识资料按任务需要及实际可访问范围使用；未提供库路径或访问能力时不声称已读取或同步，不自动建库、迁移资料或复制项目正文；只在入口变化时改导航。

## 最小收尾

- 写入前重读拟修改的现有文件，保留用户及其他工具新增内容；仅核对本次来源、链接、重复项与敏感信息，不为文档变动重跑无关测试。
- 仅入口或重要长期事实发生变化时更新 `.ai/记忆.md`；首页以 100 行以内为维护目标，必要时拆出按需资料，不截断有效约束。
- 简要汇报更新位置。
