# 环境探针与验证采集

本文件是用户选择本仓环境探针或验证采集脚本后才读取的可选实现说明，不是通用流程或规则验收的前置要求。通用执行环境与证据要求见[开发流程](开发流程.md#执行环境与证据记录)，也可用其他合规方法满足；未使用这些脚本不等于未验证，必要证据缺失仍须如实记录。

本文不触发自动安装、调用或配置修改。工具不创建调度、提交或推送，不替调用者扩大命令权限；被运行命令必须在本次任务授权范围内。其他可选实现见[工具接入](../工具接入.md)。

## 单次验证采集

[Invoke-Verification.ps1](../../scripts/Invoke-Verification.ps1) 使用程序路径与参数数组启动一次命令，不拼接 shell 命令。参数：

| 参数 | 含义 |
|---|---|
| `Executable` | 绝对可执行文件路径，或可解析为 Application 的命令名 |
| `ArgumentList` | 字面字符串数组，可为空；不要把整个命令拼成一个字符串 |
| `WorkingDirectory` | 已存在的绝对工作目录 |
| `OutputDirectory` | 尚不存在的新绝对输出目录，父目录须存在；不能覆盖旧记录 |
| `InputFile` | 本检查实际依赖的显式绝对文件清单，可为空；不递归发现依赖 |
| `TimeoutSeconds` | 超时秒数，默认 300 |
| `Repository`、`TargetRef` | 可选的 Git 仓库及目标引用；仅针对指定仓库取证 |
| `TimeZone` | 记录时区，默认 `Asia/Shanghai` |

PowerShell 7.3+ 示例；路径变量须替换为实际绝对路径，输出目录父级提前准备。参数数组通过 PowerShell 脚本调用传入，避免原生 `-File` 对数组绑定的差异：

```powershell
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
$capture = @{
    Executable = (Get-Command pwsh -CommandType Application | Select-Object -First 1).Source
    ArgumentList = @('-NoProfile', '-File', "$projectRoot/tests/check.ps1")
    WorkingDirectory = $projectRoot
    OutputDirectory = "$evidenceRoot/check-run-01"
    InputFile = @("$projectRoot/tests/check.ps1", "$projectRoot/src/target.ps1")
    Repository = $projectRoot
    TargetRef = 'refs/heads/main' # 仅在已确认该目标时使用
}
& "$ruleRoot/scripts/Invoke-Verification.ps1" @capture
exit $LASTEXITCODE
```

输出目录保存 `result.json`、`stdout.log`、`stderr.log`。记录实际程序和字面参数、工作目录、起止及时区、当前身份和运行环境、程序指纹、输入声明清单与前后指纹、Git 上下文、真实子进程退出与采集状态；缺失输入保留文件及采集阶段，已成功指纹不丢失。原始输出保留，计划或报告只引用该次结果。

- 退出码优先级为：超时 124 → 子进程真实非零（例如 23）→ 采集失败或输入变化 2 → 0。`childExitCode`、`collectorExitCode` 和 `outcome` 分别记录命令与采集状态，数字相同不表示原因相同。启动失败不会伪造子进程退出码；退出 0 仍可能因未声明输入而是 `unverified`。
- 未提供输入清单时，输入稳定性为未知；前后哈希相同只证明两个采样时点一致，不能发现中途改动后恢复，也不证明依赖清单完整。受测程序或 Git 上下文发生变化同样需要核对。
- Git 仓库未提供时该部分不适用；提供但读取失败时明确未完成，无依赖命令仍可运行，采集失败与真实子进程退出分列。工具不运行 `git status` 或推断 dirty，调用者按项目入口补核。没有 fetch，不声明目标是远端最新。
- 不自动执行任意程序的 `--version`；记录可获得的程序文件版本与指纹。解释器、相关依赖和业务运行环境版本按本检查补充，不从文件版本猜测。
- 超时仅尝试停止本次启动的进程树，保留超时与终止结果；不把被停止的程序写成测试失败或通过。工具不是执行沙箱，不能约束受测命令自行启动的外部服务或写入。
- 输入、工作目录和输出目录拒绝不支持的路径、符号链接或目录连接，具体失败保留在结果中；无输出目录可用时仍返回失败。不检测硬链接或提供对恶意并发路径替换的沙箱隔离。
- 命令参数和原始输出会落盘。调用前确认命令不包含凭据且不会输出敏感数据；不自动读取环境变量清单、不声称日志已脱敏，真实记录不发布到通用规则仓。

## 实际环境探针

[Test-ExecutionEnvironment.ps1](../../scripts/Test-ExecutionEnvironment.ps1) 接受 `WorkingDirectory`、新 `OutputDirectory`、可选 `Repository`／`TargetRef`、`TimeoutSeconds`（默认 15）和 `TimeZone`（默认 `Asia/Shanghai`）。仅在指定新目录写入合成读写样本及证据，复用采集工具检查 PowerShell、Git、文件读写和原生退出 23 的传递。

在将执行验收的同一工具、身份、宿主及权限边界中调用。结果只证明该次探针；另一沙箱、子代理或工具必须按变化的条件核对，不能引用宿主通过替代。Git 所有权或权限失败保留原因和未验证项，不自动改 safe.directory、ACL、全局配置或安装工具；不需要 Git 的独立工作可以继续。

## 合成回归

[Test-VerificationTools.ps1](../../tests/Test-VerificationTools.ps1) 显式接收 `-TempRoot <仓库外临时目录>`，创建隔离夹具验证成功、真实非零退出、字面参数、原始输出、超时、输入变化、路径及 Git 失败等边界；不联网、不改真实仓、不自动删除夹具。

合成测试证明工具契约，不证明业务检查通过。已有验证证据的迁移按[文件整理](文件整理.md#文件存放)保留同次执行内容与映射；不修改历史 JSON 中的原始路径来伪装为新执行。
